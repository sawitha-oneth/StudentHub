# Mini Student Hub

## Mobile Application Development - Practical 03

### Features:
- Bottom Tab Navigation (Home & Live Clock)
- Stack Navigation inside Home tab (Dashboard → Details)
- ScrollView and Pressable for better UX
- Digital ID Card details screen with local image
- Background Task Simulation using setInterval (Live Clock)

### Technologies:
- React Native
- Expo
- Expo Router (File-based routing)
- @expo/vector-icons (MaterialCommunityIcons)

### Project Structure:
\`\`\`
src/app/
  (home)/
    _layout.tsx   (Stack Navigator)
    index.tsx     (Dashboard)
    details.tsx   (ID Card Details)
  _layout.tsx     (Bottom Tabs)
  clock.tsx       (Background Service)
\`\`\`

### How to Run:
1. npm install
2. npx expo start
3. Scan QR code with Expo Go app
